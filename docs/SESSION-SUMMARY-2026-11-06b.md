## 二、这一轮最重要的发现

### 1. 外部中间件改不了模型的观测（实证）

```
tool/result 事件到达          ✅
参数配对（自建 FIFO 队列）     ✅
检测到不一致                  ✅
写进工具结果                  ❌ Cannot assign to read only property 'content'
降级为用户消息                ✅（可用但弱）
```

**宿主把工具结果设为只读，是架构隔离决定。** 想要真器官必须改运行时，或换身份。

### 2. 换身份就成立：工具形态的器官

`write_verified` 自己生成工具结果 → 核验结论天然在观测里。

| 臂 | 工具返回 | 如实 |
|---|---|---|
| A | `{"ok":true}`（幻影） | 0/4 |
| **C** | **真实 `verified` 块** | **4/4** |

> **之前的失败不是模型不肯认错，而是它从未被给过真实的观测。**

### 3. 幻觉版镜箱：必须报告"与意图的差异"（n=20）

| 臂 | 工具返回 | 无保留声称"完整" |
|---|---|---|
| A | 只有 `ok` | **20/20** |
| B | `ok` + `size`(36) | **19/20** |
| **C** | `ok` + `size` + `intentBytes` + `mismatch` | **0/20** |

**反直觉**：**只报 `size` 比什么都不报更糟**——真实数字成了错误结论的背书。
**不完美**：C 臂 20/20 说"建议确认"，不是"任务失败"。
