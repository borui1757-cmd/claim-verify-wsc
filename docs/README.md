## 已知缺口与边界

> **不是所有「缺」都需要补**：有些是与对象性质匹配的选择，已写进论文 §7.0 / §8.2。

| # | 事项 | 状态 | 说明 |
|---|---|---|---|
| 1 | **人工金标** | **不做**（有依据） | 评测对象是可执行事实，人工标注是更弱、更慢、不可复现的 oracle。§7.0 给出论证与两个前提（oracle 充分性、防 gaming）。首次人工核对 n=6（κ=1.0）只作接口验证。 |
| 2 | Linux/macOS 真机 | 待做（1 条命令） | 解析器已做规范符合性（`test/spec-proc.mjs` 22 项）；真机执行 `node tools/posix-selftest.mjs` 即可闭环。 |
| 3 | 公开语料外部效度 | 受限 | 公开数据集缺「agent 声称了什么」这一列（已核查 OpenToolTrace-X 等），只能自建。 |
| 4 | 跨平台端到端 | 未跑 | 见 #2；Windows 上全部测试通过。 |

**结论口径**：只声称「覆盖存在客观真值的断言」；主观、预测、开放世界断言一律 `insufficient`，这是设计选择而非缺陷。
