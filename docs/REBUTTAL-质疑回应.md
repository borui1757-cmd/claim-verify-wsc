## #1 核心创新偏弱

**质疑**：把偏差回传、Agent 重试，本质是 Reflexion 类上下文反馈；没有更新"世界模型"；"长期降低幻觉"无证据。

**接受的部分**：完全成立。我们**不训练模型**，没有权重更新，也没有跨任务学习。

**回应**（三件事）：

1. **降调措辞**：论文已明确写"不声称新因果"（§7.6.3），并把"更新世界模型"列为 **non-goal**（第七章附）。
2. **改为"外置世界模型"**（§3.9）：
   - 账本 `worldmodel.jsonl` 记录每条核验结论（带时间戳与 TTL）；
   - 提供**记忆**（"10 分钟前成立、现在不成立"）、**自校准**（7 天反驳率 ≥50% 提醒）、**免疫**（证伪 ≥2 次升级措辞）；
   - 与"文本世界模型"路线一致（arXiv 2606.09032），区别是条目**由程序真值产生并带签名**。
3. **长期证据的获取方式已经内置**：`node bin/worldmodel.mjs --rate` 输出逐周反驳率。

**残余风险**：长期曲线还**没有数据**（需要真实使用数周）。在此之前，论文只能写"机制已就绪、效果待观察"。

## #2 声明从哪来

**质疑**：预期状态由 Agent 自己生成，它可能只声明"文件存在"，不声明内容正确。

**回应**（两步，都有数据）：

1. **问题被量化**：1,086 个案例、18,066 个动作，**仅 6.4% 被提及**；**命令披露率 0.2%**；**632 个含失败案例中 91.8% 从未提失败**（`eval/reporting-gap.mjs`）。
2. **解法被验证**：同一任务（一次写 10 个文件）下，
   - 自由文本报告：覆盖率 **22.5%**
   - 结构化声明（`report_claims`）：覆盖率 **100%**
   （`eval/structured-report.mjs`）

**结论**：瓶颈在**报告形式**，不是模型有意隐瞒；这为"结构化声明是前置条件"提供了直接证据。

**残余风险**：n=4、单模型、动作类型单一（写文件）；A 臂用子串匹配，22.5% 是下界。

## #3 覆盖面有限、回滚对副作用无效

**质疑**：文件系统好验证，网络/数据库/远程服务难；回滚对发邮件、调 API 无效。

**回应**：

1. **新增原语**：`git_head`（读 `.git`，不依赖 git 命令）、`git_clean`、`http_status`（仅 http/https，2s 超时），原语总数 12 → **14**。
2. **边界写进论文**（§3.5）：
   > 对**经由受控原语执行的动作**提供原子性与撤销；对任意 shell 副作用只做核验，不做回滚。
3. **回滚的必要性被实验反驳**（§7.6.5）：
   | 臂 | 任务成功率 |
   |---|---|
   | 无核验 | 0% |
   | **仅回滚** | **17%** |
   | 回滚+反馈 | 100% |

**残余风险**：数据库、云资源原语尚未实现；跨机器真值不在范围内（已列 non-goal）。

---

## #4 威胁模型不清

**质疑**：签名只证明记录没被篡改，不证明核验正确；私钥谁持有？Agent 能否触及核验器？TOCTOU？

**回应**：新增「威胁模型与非法目标」专节（第七章附），含三张表：

1. **必须信任的组件（TCB）**：OS/文件系统、原语只读性（属性测试 120 次执行后文件不变）、签名私钥（用户自助、不入库）、时钟（RFC 3161 锚定）。
2. **威胁覆盖表**：agent 篡改回执 ✅；agent 改核验器代码 ❌（部署期隔离问题）；伪造轨迹 ❌；TOCTOU ⚠️ 部分（瞬态原语 + 时序对时）；私钥泄漏 ❌（设计外）。
3. **Non-goals**：不证明任务做对、不回滚任意副作用、不判主观、不提供身份真实性、不跨机器。

**补一句明确语义**（写入回执说明）：

> 回执证明「**某人给出了这个判定**」，不证明「**该判定在语义上正确**」——后者依赖核验器实现（§7.5 属性测试）与真值源（OS），本回执不为其提供密码学保证。

## #5 场景 C 偏平凡

**质疑**：本质是"没有 oracle 就返回 UNKNOWN"。

**回应**：我们做的比"返回 UNKNOWN"多两层：

1. **翻译见证**（`makeWitness`）：模型生成的检查计划里，**每个参数必须在原句里有出处**；对不上就返回 `insufficient`，而不是硬判。例：模型可能把"服务通了"翻成"端口监听"，见证会拒绝这种偷换。
2. **弃权有类型**：`insufficient` 会区分"无证据""证据不足""无法形式化"，并写入覆盖率统计（`coverage` 字段）。

**残余风险**：这仍是"保守策略"，它降低误判但**不提高召回**。

## #6 评估偏 toy

**质疑**：四个场景只是功能演示，不能证明有效性。

**回应**（现在的证据栈）：

| 层 | 内容 | 规模 |
|---|---|---|
| 构造基准 | 报告–轨迹基准 | 3,665 条（真 3,511 / 假 154） |
| 对照 | 同批 LLM 判官 | F1 83.6% vs 100% |
| 反循环 | 控制实验 A/B/C | B、C 各 −100pp |
| 不变量 | 蜕变 9 条 + 变异 5 条 + 属性 640 次 | 全通过 |
| 实现独立 | 差分测试（两套实现） | 一致率 99.86% |
| 行为实验 | 四组：谎报 / 任务成功 / 回滚 vs 反馈 / 通道 vs 措辞 | n=6–8 |

**残余风险**：仍未在**第三方 agent 框架**（Claude Code hooks、OpenHands、MCP）上集成，也没有公开 benchmark 子集。
